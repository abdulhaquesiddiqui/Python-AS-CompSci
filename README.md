# Python AS CompSci

Python practice from Year 12 AS Computer Science (WJEC). Class exercises, revision tasks and a few things I made for fun.

It's practice code, not a finished project, so expect it to be rough in places.

## What's in here

**Searching and sorting**
- `BubbleSort.py`, `BubbleSortWJoslin.py`
- `BinarySortWJoslin.py` (binary search)
- `LinearSort.py` (linear search)

**Validation and data handling**
- `ValAndVer.py` (validation and verification)
- `ISBN.py` (ISBN check digit)
- `Details.py`, `ClientsPlumber.py`, `Plumber.py`

**Maths and calculations**
- `Area of Circle.py`, `Area of Circle CALC.py`
- `Mean.py`, `PrimeNumbers.py`, `Number Program.py`
- `EuroTravelConversion.py`

**Games and small programs**
- `GuessTheNumber.py`, `Quiz.py`, `ChristmasQuiz.py`
- `ChristmasTree.py`, `LetterA.py`
- `EscapeChallengeOperator.py`, `EisteddfoddAgain.py`, `Holiday Checklist.py`

## Running it

Needs Python 3.

```bash
git clone https://github.com/abdulhaquemohammed1/Python-AS-CompSci.git
cd Python-AS-CompSci
python BubbleSort.py
```

Some file names have spaces, so wrap them in quotes: `python "Area of Circle.py"`
